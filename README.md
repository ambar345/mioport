# Portfolio — Ambar

Portfolio personal de Dalma Agostina Ambar Gutierrez, estudiante de Ingeniería Informática y Licenciatura en Sistemas (UNJu).

**Sitio:** https://dambarg.vercel.app

## Tecnologías

HTML, CSS y JavaScript, sin frameworks ni dependencias. Se despliega en Vercel.

## Estructura

```
.
├── index.html            # Página principal
├── css/
│   └── style.css         # Estilos
├── js/
│   └── script.js         # Menú, carruseles y animación del hero
└── assets/
    └── img/
        ├── foto.jpeg     # Foto de perfil
        └── tutorias/     # Capturas del Sistema de Tutorías FI
```

## Ver en local

Abrí `index.html` en el navegador, o levantá un servidor estático:

```bash
python3 -m http.server 8000
```
